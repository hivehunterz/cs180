# Project 0 images

Put your photos here. Use these exact lowercase filenames so `../index.html`
picks them up — GitHub Pages is case-sensitive even though Windows is not.

| File | What it is |
|---|---|
| `part1-close.jpg` | Portrait, camera close to face |
| `part1-far.jpg` | Portrait, stepped back + zoomed in |
| `part2-zoomed.jpg` | Building, far away + zoomed in |
| `part2-close.jpg` | Building, walked up + no zoom |
| `dolly-zoom.gif` | The animated dolly zoom |
| `dolly-01.jpg` … | Individual dolly zoom stills |

Resize to roughly **1600px on the long edge** before committing. Straight-from-phone
photos are 3–8 MB each and will make the page load slowly.

Delete this file once your images are in.
